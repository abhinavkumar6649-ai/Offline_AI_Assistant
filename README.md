# 🤖 Project Jarvis - Offline AI Assistant

An offline AI Voice Assistant built completely in Python using local AI models.

## 🚀 Features

- 🧠 Offline AI using Ollama + Gemma
- 🎤 Voice Input (Coming Soon)
- 🔊 Voice Output (Coming Soon)
- 💬 Chat Interface
- 🧠 Conversation Memory (Coming Soon)
- 💻 System Automation (Coming Soon)
- 📂 File Search (Coming Soon)
- 👁️ Vision (Coming Soon)

---

## 🛠️ Tech Stack

- Python 3.x
- Ollama
- Gemma 3
- Whisper (Speech-to-Text)
- Piper TTS (Text-to-Speech)

## ⚙️ Installation

```bash
git clone <repository-url>
cd Offline_AI_Assistant

python3 -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt
```

---

## ▶️ Run

```bash
python3 main.py
```
